# 용어집

상태: 이 문서는 현재 구현을 기술한다

| 용어 | 의미 |
|---|---|
| 채널(Channel) | 메시지가 전달되는 매체 (이메일, 앱 푸시 등) |
| 어댑터(Adapter) | 채널별 프로토콜을 Sendway 공통 인터페이스로 연결하는 구성요소 |
| 발송 작업(Dispatch Job) | 발송 요청 하나의 처리 단위 |
| 템플릿(Template) | 재사용 가능한 메시지 내용 형식 |
| 발송 이력(History) | 과거 발송 작업 기록 |
| 자격증명(Credential) | 채널 연동에 필요한 접속 정보 (SMTP 계정, FCM/APNs 키 등) |
