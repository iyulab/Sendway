# 아키텍처

상태: 이 문서는 현재 구현을 기술한다

## 배포 모델

Sendway는 채널 어댑터·발송 처리·템플릿 렌더링 코어 로직을 공유하는 두 경로로 시작할 수 있습니다.

- **SDK** — C# 라이브러리로 기존 .NET 프로젝트에 직접 포함합니다. 별도 서비스 프로세스가 없습니다.
- **Docker 서비스** — 독립 실행형 서비스 이미지로, 언어에 관계없이 HTTP API로 호출합니다. 관리형 클라우드 인스턴스(여러 소비 서비스가 공유)나 자체 온프레미스 환경 모두에 이 형태로 배포합니다.

저장소(발송 이력·템플릿·자격증명)는 두 경로 모두에서 같은 인터페이스로 추상화됩니다 — SDK 모드는 소비 서비스가 자체 저장소를 연결하고, Docker 서비스 모드는 Sendway가 자체 저장소를 갖습니다.

## 데이터 소유

Sendway가 저장하는 것:

- 발송 이력
- 메시지 템플릿
- 채널 자격증명(SMTP 계정, FCM/APNs 키 등) — 암호화하여 저장합니다

Sendway가 저장하지 않는 것:

- 수신자 신원 정보 — 매 요청마다 호출하는 서비스가 전달합니다
- 구독 설정

## 통합 인터페이스

소비 서비스가 발송을 요청하면, Sendway는 즉시 접수 응답을 반환하고 실제 발송은 비동기로 처리합니다. 재시도와 실패 처리는 Sendway 내부 큐가 담당합니다. 발송 결과는 상태 조회 API로 확인합니다.

## 확장 축

새 채널은 공통 인터페이스를 구현하는 어댑터를 추가하는 방식으로 확장합니다.
