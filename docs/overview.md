# 개요

상태: 이 문서는 현재 구현을 기술한다

## 문제

여러 백엔드 서비스가 이메일, SMS, 앱 푸시, 슬랙/텔레그램 같은 메시지 발송 기능을 각자 구현합니다. 특히 앱 푸시는 인증서 발급, 디바이스 토큰 관리 같은 절차가 서비스마다 반복됩니다.

## 대상 사용자

Sendway는 서비스에 메시지 발송 기능을 통합하려는 백엔드 개발자를 위한 도구입니다. 발송 이력을 열람하는 운영자용 화면은 제공하지 않습니다.

## 역할

Sendway는 메시지 발송만 전담하는 게이트웨이입니다. 수신자가 누구인지(신원 정보)는 소유하지 않으며, 호출하는 서비스가 매 요청마다 수신자 주소나 토큰을 전달합니다. 발송 이력, 메시지 템플릿, 채널 연동에 필요한 자격증명은 Sendway가 관리합니다.
