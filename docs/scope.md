# 범위

상태: 이 문서는 현재 구현을 기술한다

## In

- 이메일, SMS, 앱 푸시 메시지 발송 — 다른 채널(슬랙·텔레그램 등)은 필요가 생기면 어댑터로 추가
- 채널별 연동, 재시도, 발송 이력 관리
- 채널 자격증명(SMTP 계정, Microsoft Graph 앱, FCM 서비스 계정, SOLAPI API 키) 관리

## Out

- 수신자 신원 정보 관리 — 호출하는 서비스가 매 요청마다 전달합니다
- 구독 설정(수신 동의, 채널별 선호) 관리
- 메시지 템플릿의 저장과 렌더링 — 호출하는 서비스가 완성된 내용을 전달합니다
- 대량 마케팅 캠페인성 발송 — SMS도 정보성 발송만 다룹니다(광고 표기·수신거부 번호·야간 제한 같은 광고 규정은 처리하지 않음)
- 발송 이력을 보여주는 운영자용 대시보드
