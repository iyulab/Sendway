# 개념

상태: 이 문서는 현재 구현을 기술한다

## 채널(Channel)

메시지가 전달되는 매체(이메일, 앱 푸시 등). 채널마다 어댑터가 하나씩 존재합니다.

## 어댑터(Adapter)

채널별 발송 프로토콜(SMTP, FCM/APNs 등)을 Sendway의 공통 인터페이스로 연결하는 구성요소.

## 발송 작업(Dispatch Job)

발송 요청 하나가 접수되어 완료(성공/실패)될 때까지의 처리 단위. 비동기로 처리되며 재시도 대상이 됩니다.

## 템플릿(Template)

메시지 내용의 재사용 가능한 형식. 채널·용도별로 버전 관리됩니다.

## 발송 이력(History)

과거 발송 작업의 기록. 상태 조회 API로 열람합니다.

## SDK 모드 / Docker 서비스 모드

Sendway를 시작하는 두 경로. SDK 모드는 라이브러리를 자신의 .NET 프로젝트에 직접 포함하고, Docker 서비스 모드는 독립 실행형 서비스를 띄워 HTTP API로 호출합니다. 두 모드는 동일한 코어 로직을 공유하며, 저장소 연결 방식만 다릅니다.
